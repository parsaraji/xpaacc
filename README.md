# سامانه هوشمند مدیریت گزارش‌های آزمایشگاهی و حساب مشتریان (Lab & Ledger Manager)

سامانه پیشرفته و هوشمند حاضر، یک برنامه دسکتاپ بومی و مدرن برای سیستم‌عامل ویندوز است که با هدف بارگذاری، نمایش، استخراج خودکار فیلدهای اطلاعاتی و ساختار جداول از فایل‌های گزارش آزمایشگاه با فرمت‌های **XPS/OXPS/PDF** و همچنین مدیریت جامع اطلاعات مشتریان و حسابداری دوطرفه (به صورت کاملاً راست‌به‌چپ و فارسی) طراحی و توسعه یافته است.

## 🚀 ویژگی‌های کلیدی سامانه
1. **نمایشگر حرفه‌ای اسناد XPS/OXPS/PDF**: بدون هیچگونه به‌هم‌ریختگی ظاهری، با امکان زوم و پیمایش صفحات.
2. **استخراج هوشمند مبتنی بر چیدمان (Layout-aware)**: ردیابی دقیق مختصات متن و بازسازی کامل ساختار جداول آزمایشگاهی.
3. **دفتر کل حسابداری مستقل هر مشتری (Ledger)**: پشتیبانی از تراکنش‌های مالی بدهکار، بستانکار، فاکتور، دریافت و پرداخت، لغو ایمن تراکنش‌ها و بروزرسانی خودکار مانده حساب.
4. **سیستم پشتیبان‌گیری و بازیابی فشرده (ZIP)**: تهیه پشتیبان کامل از دیتابیس محلی SQLite و آرشیو فایل‌ها با یک کلیک.
5. **خروجی اکسل و PDF**: خروجی پرونده‌ها و صورتحساب‌ها با فرمت‌های استاندارد.
6. **رابط کاربری تیره و روشن مدرن (Modern Dark/Light Themes)**: طراحی کاملاً فارسی و منطبق بر استانداردهای زیبایی‌شناختی.

## 🛠️ نصب و راه‌اندازی سریع توسعه‌دهندگان

### ۱. نیازمندی‌های سیستم
* پایتون نسخه ۳.۱۱ یا بالاتر
* پکیج‌های توسعه دسکتاپ PySide6
* موتور پردازش اسناد PyMuPDF (fitz)
* ابزار OCR محلی Tesseract (اختیاری جهت fallback اسناد اسکن شده)

### ۲. نصب بسته‌ها
کافیست دستور زیر را در ترمینال یا خط فرمان اجرا نمایید:
```bash
pip install -r requirements.txt
```

### ۳. اجرای برنامه
```bash
python main.py
```

## 🛠️ ساخت نسخه نهایی ویندوز (Executable)

جهت کامپایل و تهیه فایل تک-اجرایی برنامه برای ویندوز با استفاده از PyInstaller، از دستور زیر یا اسکریپت `build_exe.bat` استفاده کنید:
```bash
pyinstaller --noconfirm --windowed --name "LabCustomerLedger" main.py
```

## 💼 قواعد حسابداری مشتریان (Accounting Convention)
* تراکنش‌های **بدهکار (Debit)** بدهی مشتری به آزمایشگاه را افزایش می‌دهند (مانند ثبت فاکتور خدمات).
* تراکنش‌های **بستانکار (Credit)** بدهی مشتری را کاهش می‌دهند (مانند ثبت مبالغ دریافتی یا تخفیف‌ها).
* مانده مثبت نشان‌دهنده **بدهکار بودن (Debtor)** مشتری و مانده منفی نشان‌دهنده **بستانکار بودن (Creditor)** مشتری است.
* کلیه تراکنش‌های ثبت شده دائم بوده و جهت حفظ یکپارچگی مالی، حذف فیزیکی نمی‌شوند؛ بلکه فقط به شکل برگشت تراکنش (Reversal) اصلاح می‌گردند.
